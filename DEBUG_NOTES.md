# Отладка программы (п. 6.6 ПР1)

## Что делать в IDE (PyCharm / VS Code)

1. Открыть `main_buggy_example.py` — это копия `main.py` с одной намеренно
   внесённой ошибкой в функции `get_podcast_info()`.
2. Поставить **breakpoint** на строке:
   ```python
   rating_rounded = round(rating, 1)
   ```
3. Запустить файл **в режиме отладки** (Debug), а не обычным запуском.
4. Выполнить программу пошагово (**Step Over**) до остановки на breakpoint.
5. В панели переменных отладчика посмотреть значение `rating`:
   - ожидалось: число (`float`) вроде `4.8`;
   - фактически: строка (`str`) `'4.8'`.
6. Сделать ещё один шаг (**Step Over**) — программа упадёт с ошибкой:
   ```
   TypeError: type str doesn't define __round__ method
   ```

## Причина ошибки

В `get_podcast_info()` строка
```python
rating = rating_raw
```
не преобразует входные данные — рейтинг остаётся строкой `"4.8"`, а не
приводится к `float`. Функция `round()` не умеет работать со строками,
отсюда и `TypeError`.

## Исправление

```python
rating = float(rating_raw)   # преобразование типов: строка -> число
```

Исправленная версия — рабочий файл `main.py`. Запуск после исправления:

```

Подкаст: Разбор Полётов
Тема: Технологии
Рейтинг: 4.8 (высокий рейтинг)
Длительность эпизода: 1 ч 35 мин
Статус: доступен

Резар подписался(лась) на «Разбор Полётов» 2026-09-20.
```

## Вывод

Упражнение показывает, зачем нужно явное преобразование типов при работе
с данными, которые приходят в виде строк (например, из формы ввода или
внешнего источника): без `float()` программа выглядит рабочей ровно до
момента, когда значение впервые используется как число.
