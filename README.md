# Сервис поиска подкастов по темам

## Назначение
Приложение помогает пользователям быстро находить подкасты по интересующим
их темам (технологии, наука, бизнес, здоровье и т. д.), не пролистывая
вручную каталоги подкаст-платформ. Сервис хранит информацию о подкастах,
классифицирует их по темам и позволяет пользователям подписываться на
понравившиеся подкасты.

## Целевая аудитория
Слушатели подкастов, которые ищут контент по конкретной теме: студенты и
специалисты, подбирающие профильные подкасты для обучения; люди, изучающие
новую область и ищущие тематическую подборку; обычные слушатели, желающие
найти новые подкасты по интересам без ручного перебора каталогов.

## Предметная область
Каталогизация и тематический поиск подкастов: ведение базы подкастов с
привязкой к темам, поиск подкастов по теме или ключевому слову, оформление
пользовательских подписок на подкасты и получение персональных рекомендаций
на основе подписок.

## Основные сущности
- Пользователь — учётная запись слушателя, который ищет подкасты и оформляет подписки.
- Подкаст — карточка подкаста: название, тема, рейтинг, длительность эпизода, доступность.
- Тема — категория, к которой относится подкаст (используется при поиске и фильтрации).
- Подписка — связь между пользователем и подкастом, на который он подписан.

## Основные функции
- Поиск подкастов по заданной теме или ключевому слову.
- Просмотр карточки подкаста с рейтингом и длительностью эпизода.
- Оформление подписки пользователя на подкаст.
- Определение уровня рейтинга подкаста (высокий / средний / низкий) для сортировки результатов поиска.

## План развития
На следующих этапах планируется:
- разработка веб-приложения на Django;
- подключение базы данных для хранения подкастов, тем, пользователей и подписок;
- реализация регистрации и аутентификации пользователей;
- разработка REST API для поиска подкастов и управления подписками;
- контейнеризация приложения (Docker);
- настройка CI/CD.
